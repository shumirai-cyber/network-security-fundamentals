# Activity 1: Understanding Computer Networks

## 1. Objective

The objective of this activity was to understand the basic purpose of computer networks and use a Windows command to inspect my computer's network configuration.

## 2. What Is a Computer Network?

A computer network is a group of connected devices that communicate and share information or resources. Networks allow devices to access services such as websites, email, shared files, printers and the internet.

## 3. Practical Task

I used the Windows Command Prompt to run the following command:

`ipconfig`

This command displays IP configuration information for network adapters on a Windows computer.

## 4. Findings

The command displayed information about my computer's network adapters.

The output included:

* **Network adapters:** Interfaces that allow a device to connect to a network.
* **IPv4 address:** An address used to identify a device on an IPv4 network.
* **Subnet mask:** Helps identify the network portion of an IPv4 address.
* **Default gateway:** The router or other device that normally forwards traffic from the local network to other networks.
* **IPv6 information:** Address information used by IPv6 networking.
* **Connection status:** Some adapters showed that their media was disconnected.

## 5. Security and Privacy Considerations

Network configuration information is useful for troubleshooting, but screenshots can reveal details about a device or local network. Before publishing evidence, I removed sensitive network values that I did not need to demonstrate the task.

## 7. What I Learned

I learned how to use `ipconfig` to inspect Windows network configuration. I also learned the purpose of IP addresses, subnet masks and default gateways, and why network information should be reviewed before sharing screenshots publicly.

## 8. Conclusion

This activity introduced me to basic computer networking and Windows network troubleshooting. It provides a foundation for the next activities on IP addressing, ports, protocols and network security.

## 9. Scope

This exercise used a standard command on my own Windows computer. No unauthorised network scanning or testing was performed.
