# Network Security Fundamentals

## Project Overview

This beginner-friendly cybersecurity project explores computer networking, common network threats, and defensive security practices through practical exercises and documented findings.

## Project Objectives

* Understand basic networking concepts, IP addresses, ports, and protocols.
* Explore DNS, DHCP, routers, switches, and firewalls.
* Learn about common network attacks and defensive measures.
* Practise safe network investigation using Windows tools.
* Capture screenshots as evidence of practical work.
* Document findings and recommend security improvements.

## Activities

1. Understanding Computer Networks
2. IP Addresses and Subnet Basics
3. Understanding Network Ports and Protocols
4. DNS, DHCP and How Devices Connect
5. Routers, Switches and Network Devices
6. Firewalls and Network Security Rules
7. Common Network Attacks and Threats
8. Wi-Fi Security and Secure Connections
9. Introduction to Network Traffic Analysis
10. Practical Network Investigation Using Windows Tools
11. Network Security Findings and Recommendations
12. Final Review and Lessons Learned

## Evidence and Documentation

Practical screenshots and activity reports will be organised in the repository as the project progresses. Evidence will show genuine results from my own learning exercises.

## Tools

* Windows Command Prompt
* Windows PowerShell
* Windows Security settings
* GitHub and Markdown documentation
* Additional network analysis tools where appropriate

## Safety and Scope

Practical activities will be limited to my own device, authorised networks, and safe learning exercises. No unauthorised scanning or testing will be performed.

## Skills Developed

* Networking fundamentals
* Basic network troubleshooting
* Security awareness
* Evidence collection and documentation
* Technical communication
* Security analysis and recommendations
