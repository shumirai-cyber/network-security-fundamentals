# Activity 8: Wi-Fi Security and Secure Connections

## 1. Introduction

Wi-Fi security is important because wireless networks allow devices to communicate without physical cables. If a wireless network is not properly secured, unauthorised users may be able to connect to it, monitor inadequately protected traffic, or attempt to trick users into connecting to a malicious hotspot.

The purpose of this activity is to understand common Wi-Fi security risks, wireless encryption methods, safe connection practices, and ways to protect devices when using wireless networks.

## 2. Learning Objectives

The objectives of this activity are to:

* Understand the importance of Wi-Fi security.
* Identify common wireless network threats.
* Understand the differences between WPA2 and WPA3 encryption.
* Recognise the risks associated with public Wi-Fi.
* Identify methods of securing wireless connections.
* Recommend good practices for protecting wireless networks.

## 3. Understanding Wi-Fi Security

Wi-Fi security involves protecting wireless networks against unauthorised access, interception, and other security threats.

A secure wireless network should use an appropriate encryption standard, a strong password, updated router firmware, and suitable network settings.

### Wireless Encryption Standards

**WEP (Wired Equivalent Privacy)**

WEP is an outdated wireless security protocol with serious security weaknesses. It should not be used because attackers can break its protection using readily available techniques.

**WPA (Wi-Fi Protected Access)**

WPA was introduced to improve upon WEP but has since been superseded by stronger security standards.

**WPA2 (Wi-Fi Protected Access 2)**

WPA2 provides stronger security than WEP and original WPA. When WPA3 is unavailable, WPA2 using AES-based encryption is generally a suitable choice for a home network.

**WPA3 (Wi-Fi Protected Access 3)**

WPA3 is a newer wireless security standard that provides improved protection against certain password-guessing attacks and strengthens wireless security. It should be preferred when supported by the router and connected devices.

## 4. Common Wi-Fi Security Threats

### 4.1 Unauthorised Network Access

Unauthorised access occurs when someone connects to a wireless network without permission. Weak passwords and insecure router settings can increase this risk.

**Prevention:** Use a strong, unique Wi-Fi password and modern encryption.

### 4.2 Rogue and Fake Wi-Fi Hotspots

An attacker may create a malicious hotspot that imitates a legitimate public network. Users who connect to it may expose themselves to phishing pages, traffic interception, or other attacks.

**Prevention:** Verify the network name with an official source before connecting. Avoid unfamiliar hotspots that appear suspicious.

### 4.3 Man-in-the-Middle Attacks

A man-in-the-middle attack occurs when an attacker positions themselves between communicating parties in an attempt to intercept or manipulate information.

**Prevention:** Use HTTPS websites, keep devices updated, avoid ignoring certificate warnings, and use a reputable VPN when appropriate.

### 4.4 Weak Wi-Fi Passwords

Short, predictable, or reused passwords can make it easier for attackers to gain access to a wireless network.

**Prevention:** Use a long, unique password that is difficult to guess and do not share it unnecessarily.

### 4.5 Outdated Router Firmware

Router firmware that is no longer updated may contain known security vulnerabilities.

**Prevention:** Install updates from the router manufacturer and replace equipment that no longer receives essential security updates when necessary.

## 5. Public Wi-Fi Security

Public Wi-Fi is commonly available in cafés, airports, hotels, libraries, and shopping centres. Although these networks are convenient, their security varies.

Potential risks include fake hotspots, insecure network configurations, and attempts to exploit vulnerable devices or inadequately protected connections.

The following precautions can reduce risk:

* Confirm the correct network name before connecting.
* Prefer HTTPS websites when browsing.
* Keep the operating system, browser, and security software updated.
* Disable automatic connection to unfamiliar Wi-Fi networks.
* Avoid installing software or accepting unexpected certificates at the request of a public hotspot.
* Use a reputable VPN when additional protection is appropriate.
* Disconnect from networks that are no longer needed.
* Use mobile data for sensitive activities when a public network cannot be trusted.

HTTPS encrypts information between a browser and a website, helping protect data in transit. A VPN can provide an additional encrypted connection between a device and the VPN service, but it does not make every website or network automatically safe.

## 6. Securing a Home Wi-Fi Network

A home wireless network can be made more secure by following these recommendations:

1. Use WPA3-Personal where supported, or WPA2 with AES when WPA3 is unavailable.
2. Set a strong, unique Wi-Fi password.
3. Change default router administrator credentials.
4. Update the router firmware regularly.
5. Disable WPS if it is not needed and can be safely disabled.
6. Disable remote administration if it is unnecessary.
7. Create a guest network for visitors and untrusted devices when supported.
8. Review connected devices periodically.
9. Replace unsupported routers that no longer receive security updates.

These measures help reduce the likelihood of unauthorised access and improve the security of connected devices.

## 8. Security Recommendations

Based on this activity, the following recommendations are appropriate:

* Prefer WPA3 or WPA2-AES encryption.
* Use strong, unique passwords for wireless networks and router administration.
* Keep router firmware and connected devices updated.
* Verify public hotspot names before connecting.
* Avoid automatically joining unfamiliar networks.
* Use HTTPS and consider a reputable VPN on untrusted networks.
* Disable unnecessary wireless and router features.
* Never attempt to access another person's network without permission.
